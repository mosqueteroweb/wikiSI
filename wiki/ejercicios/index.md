# Ejercicios Prácticos Resueltos

Píldoras prácticas breves enfocadas en **una destreza técnica concreta** (un comando de consola, un esquema de particionado, la configuración de una interfaz de red o la gestión de permisos), diseñadas para ejecutarse en el laboratorio del aula (**MAX + Oracle VirtualBox**).

Cada ejercicio incluye:

- Objetivo y criterios de evaluación (`RAx.CEy`) trabajados.
- Especificación del sistema invitado (Windows 10/11, Ubuntu, Linux Mint o Puppy Linux) y RAM asignada.
- Enunciado breve y **resolución paso a paso** en pestañas comparativas o bloques desplegables.

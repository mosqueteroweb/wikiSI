# wikiSI · Sistemas Informáticos (0483 · 1º DAM)

Base de conocimiento curricular, píldoras prácticas y laboratorios de aula para el módulo profesional **Sistemas Informáticos (Código 0483)** de **1º de Desarrollo de Aplicaciones Multiplataforma (DAM)**, construida siguiendo el patrón **LLM Wiki** y adaptada al entorno real del aula.

> **Referencia curricular oficial:** [Relación Resultados de Aprendizaje - Contenidos (Módulo 0483)](https://mosqueteroweb.github.io/ismie01/DAM/dam_si_relaciones.html)

---

## Entorno de Laboratorio del Aula

Todas las guías, comandos y prácticas están diseñadas y verificadas para el equipamiento estándar del aula:

| Parámetro del aula | Especificación obligatoria |
| :--- | :--- |
| **Sistema anfitrión (Host)** | **MAX (MAdrid_linuX)** (base Ubuntu/Debian) |
| **Hipervisor** | **Oracle VirtualBox** sobre MAX |
| **Presupuesto máximo de RAM (VMs)** | **10–12 GB totales** simultáneos en equipos de 16 GB (reservando 4–6 GB para el host MAX) |
| **Sistemas invitados (Guests)** | Windows 10, Windows 11, Ubuntu (Desktop/Server), Linux Mint y Puppy Linux |

## Catálogo Maestro por Resultados de Aprendizaje (RA1 – RA7)

La construcción de la wiki avanza de forma secuencial desde **RA1** hasta **RA7**, integrando en cada bloque conceptos teóricos, ejercicios sencillos resueltos paso a paso y prácticas integradoras de clase.

| RA | Resultado de Aprendizaje | Criterios | Estado | Hub |
| :---: | :--- | :---: | :---: | :--- |
| **RA1** | Evalúa sistemas informáticos, identificando sus componentes y características. | `a` – `h` (8) | Completado ✅ | [Ir a RA1](ra/RA1.md) |
| **RA2** | Instala sistemas operativos planificando el proceso e interpretando documentación técnica. | `a` – `i` (9) | Completado ✅ | [Ir a RA2](ra/RA2.md) |
| **RA3** | Gestiona la información del sistema identificando las estructuras de almacenamiento y aplicando medidas para asegurar la integridad de los datos. | `a` – `h` (8) | En preparación activa | [Ir a RA3](ra/RA3.md) |
| **RA4** | Gestiona sistemas operativos utilizando comandos y herramientas gráficas y evaluando las necesidades del sistema. | `a` – `h` (8) | Planificado | [Ir a RA4](ra/RA4.md) |
| **RA5** | Interconecta sistemas en red configurando dispositivos y protocolos. | `a` – `h` (8) | Planificado | [Ir a RA5](ra/RA5.md) |
| **RA6** | Opera sistemas en red gestionando sus recursos e identificando las restricciones de seguridad existentes. | `a` – `g` (7) | Planificado | [Ir a RA6](ra/RA6.md) |
| **RA7** | Elabora documentación valorando y utilizando aplicaciones informáticas de propósito general. | `a` – `g` (7) | Planificado | [Ir a RA7](ra/RA7.md) |
